理解这些行为时，先问三个问题：**名字绑定到哪个对象？操作是在修改对象，还是重新绑定名字？表达式在什么时候求值？**

本篇对应 Notion 的 Python 第 01 模块，重点整理学习对话里的默认参数、真值与短路，并补充理解它们所需的对象、作用域与拷贝概念。来源见 [[00-Python|Python]]。

## 1. 名称绑定：赋值不会自动复制对象

`a = b` 把名字 `a` 绑定到 `b` 当前引用的对象。两个名字可以指向同一个对象；名字本身并不是装着数据的独立盒子。

```python
a = [1, 2]
b = a

b.append(3)          # 修改共同引用的列表
assert a == [1, 2, 3]
assert a is b

b = [9]              # 只把 b 重新绑定到新列表
assert a == [1, 2, 3]
assert b == [9]
assert a is not b
```

函数调用时，形参也是绑定到传入的对象。函数可以通过形参修改可变对象，但给形参重新赋值，不会让调用方的名字跟着重新绑定。

```python
def change(items):
    items.append(2)
    items = [99]     # 只改变函数内部这个名字的绑定

values = [1]
change(values)
assert values == [1, 2]
```

这里说“对象引用”比“内存地址”更准确；理解语言行为不需要假定对象的实际存储布局。

## 2. 作用域：LEGB、global 与 nonlocal

普通函数中的名字查找，可以用 LEGB 理解：**Local 本地 → Enclosing 外层函数 → Global 模块 → Builtins 内置**。如果函数内给一个名字赋值，通常就把它视为该函数的局部名字，除非声明 `global` 或 `nonlocal`。

- `global x`：后续赋值针对当前模块的 `x`，不是所有模块共享的“全局变量”。
- `nonlocal x`：针对外层函数中已有的绑定，不会创建模块变量。
- `x += 1` 也包含赋值；如果 `x` 被判定为局部名字，却在赋值前读取它，会触发 `UnboundLocalError`。

```python
def make_counter():
    count = 0

    def increment():
        nonlocal count
        count += 1
        return count

    return increment

counter = make_counter()
assert counter() == 1
assert counter() == 2
```

闭包中的自由变量一般在调用时取值，不会自动为每次循环保存一份值：

```python
def make_functions():
    return [lambda: i for i in range(3)]

assert [f() for f in make_functions()] == [2, 2, 2]

# 默认参数在每次创建函数时求值，保存当时的 i 对象
fixed = [lambda i=i: i for i in range(3)]
assert [f() for f in fixed] == [0, 1, 2]
```

LEGB 是常用理解方式；类体等作用域有额外规则，不能把类属性查找直接当成外层函数变量查找。[官方执行模型](https://docs.python.org/3/reference/executionmodel.html#resolution-of-names)

## 3. 身份、相等、可变性与哈希

| 问题 | 写法 | 含义 |
| --- | --- | --- |
| 是不是同一个对象？ | `a is b` | 比较身份 |
| 两个对象的值是否相等？ | `a == b` | 按类型的相等规则比较 |
| 能否原地改变对象？ | 可变性 | 列表可变，整数和字符串不可变 |
| 能否作为字典键或集合元素？ | 可哈希性 | 需要稳定的哈希值和相容的相等规则 |

```python
a = [1, 2]
b = [1, 2]
assert a == b
assert a is not b

value = None
assert value is None
```

判断 `None` 用 `is None`；比较数值、字符串的内容用 `==`。不要依赖整数缓存或字符串复用来推断 `is` 的结果。

`tuple` 不可变，指的是它保存的各个对象引用不能替换；被引用的对象仍可能可变。

```python
pair = ([1], "label")
pair[0].append(2)
assert pair == ([1, 2], "label")
```

可哈希对象在生命周期内的哈希值必须稳定，而且 **`a == b` 时必须有 `hash(a) == hash(b)`**；反过来不成立，不同对象可能哈希冲突。`list`、`dict`、`set` 不可哈希；`tuple` 要所有元素都可哈希才可哈希。可变性和可哈希性并不完全等价，例如默认的普通自定义类实例可以按身份哈希。[官方术语：hashable](https://docs.python.org/3/glossary.html#term-hashable)

哈希表怎样利用这些规则，见 [[02-内置类型、文本与二进制#3. 为什么 set 查值通常比 list 快]]。

## 4. 赋值、浅拷贝与深拷贝

| 操作 | 外层对象 | 内部对象 |
| --- | --- | --- |
| `b = a` | 仍是同一个 | 共享 |
| 列表的 `a[:]`、`a.copy()` | 新列表 | 元素引用仍共享 |
| `copy.deepcopy(a)` | 对普通嵌套列表创建新对象 | 递归复制内部列表 |

```python
from copy import deepcopy

original = [[1], [2]]
shallow = original.copy()
deep = deepcopy(original)

assert shallow is not original
assert shallow[0] is original[0]

shallow[0].append(9)
assert original == [[1, 9], [2]]
assert deep == [[1], [2]]

shallow.append([3])
assert len(original) == 2    # 外层没有共享
```

深拷贝也不是“所有东西都能复制”：文件、连接等资源不能照搬这个模型，自定义类也可以定义拷贝行为。是否需要复制，要看哪些状态允许共享。[官方 copy 文档](https://docs.python.org/3/library/copy.html)

## 5. 默认参数为什么会共享状态

### 默认表达式在定义函数时求值

执行 `def` 时，默认表达式就会被求值，结果保存在函数对象中。以后省略这个参数时，复用保存的对象；不是每次调用都重新执行默认表达式。[官方默认参数说明](https://docs.python.org/3/tutorial/controlflow.html#default-argument-values)

```python
def collect(item, items=[]):  # 用于展示问题，不建议这样写
    items.append(item)
    return items

assert collect(1) == [1]
assert collect(2) == [1, 2]
assert collect.__defaults__ == ([1, 2],)
```

理解为“函数保存了默认对象的引用”即可。多次调用都能改到同一个列表，因此状态会累积。

### 整数默认值为什么没有同样的问题

```python
def increment(x=10):
    x += 1
    return x

assert increment() == 11
assert increment() == 11
assert increment.__defaults__ == (10,)
```

整数不可变，`x += 1` 在这里产生加法结果并重新绑定局部名字 `x`，不会改掉函数保存的默认整数。注意 `+=` 的具体行为取决于类型：列表的 `+=` 通常会原地扩展，不能把所有类型都按整数推理。

即使默认值外层是元组，内部列表仍会被共享：

```python
def nested_default(value=([],)):
    value[0].append(1)
    return value

assert nested_default() == ([1],)
assert nested_default() == ([1, 1],)
```

### 常用写法：调用时再创建

```python
def collect_fresh(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

assert collect_fresh(1) == [1]
assert collect_fresh(2) == [2]

provided = []
assert collect_fresh(3, provided) is provided
assert provided == [3]
```

只有传入 `None` 或省略参数时才会新建列表；显式传入的列表仍会被这个函数修改。不要随意改成 `items = items or []`，否则调用方传入的空列表也会被替换。如果 `None` 本身是有效业务输入，需要另设专用哨兵对象区分“未传入”。

可变默认参数不是语法错误，但容易产生隐蔽共享状态。需要共享状态时，显式设计状态对象通常更清楚。

### dataclass 使用 default_factory

```python
from dataclasses import dataclass, field

@dataclass
class Bag:
    items: list[int] = field(default_factory=list)

a = Bag()
b = Bag()
a.items.append(1)
assert a.items == [1]
assert b.items == []
assert a.items is not b.items
```

没有显式提供该字段时，工厂为新实例创建列表。直接写列表默认值会被 dataclass 拒绝；Python 3.11 起，检查范围改为不可哈希默认值，这只是对常见可变默认值的近似防护。[官方可变默认值说明](https://docs.python.org/3/library/dataclasses.html#mutable-default-values)

## 6. 真值与短路

### if 判断的是真值，不要求对象本身是 bool

常见假值包括 `False`、`None`、数值零，以及空字符串、空列表、空元组、空字典、空集合等。自定义对象优先由 `__bool__()` 决定；未定义时可用 `__len__()`，两者都没有时通常为真。

```python
assert not None
assert not 0
assert not ""
assert not []
assert bool("0")       # 非空字符串
assert bool([False])   # 非空列表，不是判断列表元素
```

“是假值”不等于“没有提供”。例如 `0` 可能是合法配置值；只想检查缺失时用 `is None`。

### and / or 返回参与运算的对象

| 表达式 | 行为 |
| --- | --- |
| `a and b` | `a` 为假就返回 `a`，否则求值并返回 `b` |
| `a or b` | `a` 为真就返回 `a`，否则求值并返回 `b` |
| `not a` | 返回布尔值 |

```python
assert (1 and 2) == 2
assert (0 and 2) == 0
assert (1 or 2) == 1
assert (0 or 2) == 2

x = None
assert (x is not None and x > 10) is False  # 不会执行 x > 10

timeout = 0
assert (timeout or 30) == 30
assert (30 if timeout is None else timeout) == 0
```

`a or default` 会替换所有假值，只有业务上确实把这些假值都视为缺省时才合适。上述行为见[官方真值与布尔运算说明](https://docs.python.org/3/library/stdtypes.html#truth-value-testing)。

## 7. 求值顺序与优先级是两件事

一般表达式按从左到右求值，赋值先求右侧；优先级决定表达式怎样分组。短路运算和条件表达式会决定某些分支根本不执行。

```python
events = []

def mark(name, value):
    events.append(name)
    return value

result = mark("left", 2) + mark("middle", 3) * mark("right", 4)
assert result == 14
assert events == ["left", "middle", "right"]

events.clear()
result = mark("first", 0) and mark("skipped", 9)
assert result == 0
assert events == ["first"]
```

`a < b < c` 是链式比较：中间表达式只求值一次，并且也会短路；不要简单当成重复执行 `b` 的两次比较。[官方表达式求值规则](https://docs.python.org/3/reference/expressions.html#evaluation-order)
